## 2. Design Decisions

### 2.1 Three-State Toggle

Cycle: **Auto** (default) -> **Light** -> **Dark** -> **Auto** -> ...

- **Auto**: Follows `prefers-color-scheme: dark` system setting
- **Light**: Forces light theme regardless of system
- **Dark**: Forces dark theme regardless of system

### 2.2 Implementation Mechanism

- `<html data-theme="auto|light|dark">` attribute on `<html>` element
- CSS variables override in `:root[data-theme="dark"]`
- For "auto" mode: `@media (prefers-color-scheme: dark)` sets same dark variables
- Ordering: explicit `data-theme="dark"` overrides; `data-theme="auto"` defers to media query; `data-theme="light"` keeps light defaults

### 2.3 Toggle Icon

Place in the nav rail (`_nav.html`) as the last item -- below Config, above nothing.

Icons (simple SVG, matching existing nav icon style):
- Auto: monitor icon (screen with sparkle/auto indicator)
- Light: sun icon
- Dark: moon icon

On click, cycle to next state. The nav item does NOT link to a page -- it just toggles.

### 2.4 Persistence

- `localStorage.setItem('theme', 'auto'|'light'|'dark')`
- On load, read localStorage; default to `'auto'` if unset
- Apply theme synchronously in a `<script>` tag in `<head>` to prevent flash of wrong theme (FOUC prevention)

**JS functions (add to bottom of `_nav.html` or as inline script in `_theme.html`):**

```javascript
function cycleTheme() {
    var current = localStorage.getItem('theme') || 'auto';
    var next = current === 'auto' ? 'light' : current === 'light' ? 'dark' : 'auto';
    localStorage.setItem('theme', next);
    document.documentElement.setAttribute('data-theme', next);
    updateThemeIcon(next);
}

function updateThemeIcon(theme) {
    document.querySelectorAll('.theme-icon-auto, .theme-icon-light, .theme-icon-dark').forEach(function(el) {
        el.style.display = 'none';
    });
    var active = document.querySelector('.theme-icon-' + theme);
    if (active) active.style.display = '';
    var label = document.querySelector('.theme-label');
    if (label) label.textContent = theme.charAt(0).toUpperCase() + theme.slice(1);
}

// Initialize icon on page load
document.addEventListener('DOMContentLoaded', function() {
    updateThemeIcon(localStorage.getItem('theme') || 'auto');
});
```
